# Damiao Multi-Axis Arm Controller

Bộ điều khiển đa động cơ viết bằng Python cho các actuator Damiao (DM) thông qua giao tiếp USB-CAN, hướng tới ứng dụng cánh tay robot và gripper.

## Tính năng

- Quản lý CAN ID độc lập cho từng động cơ.
- Hỗ trợ điều khiển theo MIT mode.
- Thực thi quỹ đạo đồng bộ cho nhiều trục.
- Bộ công cụ Python phục vụ cấu hình và điều khiển actuator.

## Trạng thái dự án

Repository hiện đang được khởi tạo. Hướng dẫn cài đặt, cấu hình USB-CAN và ví dụ sử dụng sẽ được cập nhật khi mã nguồn và thông tin phần cứng được đưa vào repo.
